# ระบบแผนผังอาคาร

แสดงแผนผังอาคารหลายชั้น คลิกจุดบริการบนภาพผังเพื่อปักหมุดและดูรายละเอียดพร้อมรูป ค้นหาจุดได้จากรายการด้านข้าง แชร์ลิงก์ไปยังจุดได้ (`index.html#spot=<id>`)

- `index.html` — หน้าสาธารณะ
- `admin.html` — หน้าเจ้าหน้าที่: ลากบนผังเพื่อวาดจุดใหม่ · ลากจุดเพื่อย้าย · ลากมุมทองเพื่อปรับขนาด · แก้ชื่อ/รายละเอียด/รูป · เพิ่ม/ลบชั้น แล้วกด "บันทึก"
- ข้อมูลเก็บใน Google Sheet ผ่าน Apps Script (`apps-script/Code.gs`) — หน้าเว็บวางบน GitHub Pages ได้ฟรี

ยังไม่ได้ตั้ง `SCRIPT_URL` ใน `js/common.js` = **โหมดตัวอย่าง** อ่าน `data/sample.json` และปุ่มบันทึกจะดาวน์โหลดไฟล์ JSON แทน

## ติดตั้ง (ครั้งเดียว)

### 1. Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดเดิม วางเนื้อหา `apps-script/Code.gs` ทั้งไฟล์ → บันทึก
3. เลือกฟังก์ชัน `setup` → **เรียกใช้** (ครั้งแรกจะขอสิทธิ์ ให้อนุญาต) → ได้ 3 ชีต: ตั้งค่า / ชั้น / จุดบริการ พร้อมข้อมูลตัวอย่าง
4. ในฟังก์ชัน `setPassword` ใส่รหัสผ่านใน `NEW_PASSWORD` → เลือก `setPassword` → **เรียกใช้** → **ลบรหัสผ่านออกจากโค้ดทันที** แล้วบันทึก
   (ระบบเก็บเฉพาะค่า hash ใน Script Properties รหัสจริงไม่อยู่ในโค้ดหรือหน้าเว็บ)
5. **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน** · ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - คัดลอก URL ที่ลงท้ายด้วย `/exec`

### 2. หน้าเว็บ
1. เปิด `js/common.js` ใส่ URL จากข้อ 5 ใน `SCRIPT_URL`
2. อัปโหลดทั้งโฟลเดอร์ (ยกเว้น `apps-script/`, `tools/`) ขึ้น GitHub repo → **Settings → Pages → Deploy from branch: main / root**
3. เปิด `https://<ชื่อบัญชี>.github.io/<repo>/admin.html` → เข้าสู่ระบบ → เริ่มใส่ผังจริง

แก้ `Code.gs` ภายหลัง: ต้อง **การทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่** ไม่อย่างนั้น URL เดิมยังรันโค้ดเก่า

## ใส่ผังจริง
- **ภาพผัง**: แนวนอน กว้างอย่างน้อย 1600 px (PNG/JPG/SVG) วางใน `assets/` แล้วใส่ `assets/ชื่อไฟล์` หรืออัปโหลดใน Google Drive แชร์ "ทุกคนที่มีลิงก์" แล้ววางลิงก์แชร์ได้เลย (ระบบแปลงเป็นลิงก์ภาพให้)
  ใส่ใน admin → **ตั้งค่าชั้นนี้ → ลิงก์ภาพผัง**
- **ตำแหน่งจุด** เก็บเป็น % ของภาพ — ถ้าเปลี่ยนภาพผังที่สัดส่วนต่างจากเดิม ต้องลากจุดใหม่
- **รูปของจุด**: ลิงก์บรรทัดละ 1 รูป (ลิงก์แชร์ Google Drive ใช้ได้)
- ติ๊ก "แสดงในรายการค้นหา" ออก สำหรับจุดที่อยากให้อยู่บนผังแต่ไม่ต้องอยู่ในรายการ (เช่น บันได)

## ความปลอดภัย
- อ่านข้อมูลได้ทุกคน (เป็นข้อมูลสาธารณะอยู่แล้ว) · เขียนได้เฉพาะผู้ที่เข้าสู่ระบบ (token 6 ชม.)
- ใส่รหัสผิด 5 ครั้งใน 15 นาที → ล็อก 15 นาที
- ข้อความที่ขึ้นต้นด้วย `= + - @` ถูกเก็บเป็นข้อความ ไม่กลายเป็นสูตรในชีต

## แก้ผังตัวอย่าง
`python tools/make_sample.py` สร้าง `assets/floor-*.svg`, `data/sample.json` และข้อมูลตัวอย่างใน `Code.gs` ใหม่จากรายการห้องในไฟล์นั้น
